# BDD

This Codex skill intentionally bundles the whole BDD plugin into one skill so Codex users install only one entry point for BDD work.

## Workflow Selection

Choose the workflow that matches the user's request:

- Use **Discovery** when the user asks to:
  - discover a feature
  - explore behavior
  - write a feature file
  - do BDD discovery
  - do example mapping
  - explore a user story
- Use **Consistency Check** when the user asks to:
  - check consistency
  - find contradictions
  - validate BDD specs
  - check recent spec changes
  - scan `spec/` for conflicts
